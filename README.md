## Introduction

**English Chunks** is an application that helps users learn authentic English expressions. It uses AI technology to extract common English expressions (chunks) from YouTube videos and helps users naturally acquire these expressions through repeated playback (ear training), thereby improving speaking ability.

## Features

*   **AI-Driven English Chunk Extraction:** Uses AI technology to automatically identify and extract common English expressions from YouTube videos.
*   **Ear Training Practice:** Helps users naturally acquire pronunciation and usage through repeated playback of selected English chunks.
*   **YouTube Video Source:** Uses rich YouTube videos as learning materials to ensure authenticity and practicality of learning content.
*   **100% Written by Cursor, 0% Human Input:** All code in this project was written by [Cursor](https://cursor.sh/), with no manual code writing throughout the development process, including project setup, coding, debugging, etc.
